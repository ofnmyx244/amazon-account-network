## 亚马逊官方对开店网络有硬性要求吗？

没有。官方对网络只字未提，要求集中在资料和验证两个环节。

注册阶段要准备的资料，官方列得很清楚：公司营业执照彩色扫描件（距过期日期要超过45天，公司处于存续状态）、法定代表人身份证或护照（姓名要和营业执照、注册账号完全一致）、一张能国际付款的VISA或MasterCard（不要用虚拟卡）、准确且最新的联系方式，以及用于收款的银行账户——国内账户、海外/香港账户、第三方支付服务商账户三选一。

资料交上去之后，还有几道验证等着：身份验证可以选拍摄面部照片或录制面部视频，中国大陆卖家还要补交一张营业执照照片；地址验证靠亚马逊邮寄的实体明信片，通常5到8个工作日寄到，把验证码填进后台就算完成。北美站有税务信息审核，欧洲站有KYC审核，加拿大站也在逐步上线资质审核。

你会发现，这一整套流程里没有任何一步问“你用的是不是固定IP”。原因很简单：网络不碰审核红线，碰的是账号安全，这就要说到关联机制了。

## 真正的网络要求：账号关联是怎么判定的

亚马逊判定几个账号是否属于同一个人，主要看三类信息，其中两类和网络设备直接相关。

操作端包括网卡MAC地址、浏览器Cookies、Flash对象和硬盘信息——这也是为什么“换电脑”没那么简单，重装系统只是最基础的一步。网络端看的是路由器MAC地址和外网IP地址，在同一根宽带下操作两个账号，等于主动告诉系统“这是我们俩”。剩下的是账户信息：信用卡、收款方式、电话号码、邮箱、注册地址，任何有唯一性的私人信息都不能在多个账号之间重复。

关联本身不一定立刻出事，但风险是实打实的：一个账号因为侵权或违规被封，和它关联的账号会跟着受牵连；同站点关联的账号如果交叉销售同样的产品，亚马逊会要求强制删除其中一个账号的Listing，不删的话两个账号可能一起被关闭。

还有一条底线要先说清楚：亚马逊规则规定同一个人只能注册一个卖家账户。网络隔离能降低的是“被误判关联”的风险，前提是每个账号背后本来就是不同的公司资料和主体。想用同一套资料开两个店，换什么IP都救不回来。

## 单账号开店：注册前的网络环境清单

网络环境要赶在注册之前准备好，出事之后再补救要麻烦十倍。照着这份清单过一遍：

1. 一台干净的电脑——最好从头到尾没登录过其他亚马逊卖家账号，买家账号也算；
2. 一个独享的外网IP——家用宽带或者独立IP的VPS都可以，关键是这个出口没有和其他卖家共用；
3. 注册完成后固定在同一套环境里操作——电脑、路由器、IP尽量不动，账号绑定的邮箱也只在这台电脑上登录；
4. 别在这台电脑的浏览器里登录无关的亚马逊买家账号——卖家账号和买家账号之间同样存在关联；
5. 日常运营别用手机——手机会自动连接已知WiFi，外网IP完全不可控；反而是“干净的笔记本+无线网卡”是可行的，无线网卡的IP不会和其他人相同。

这五条的成本几乎为零。前两条做到位，单账号的关联风险就已经压到很低了。

## 常见问题

### 注册和运营亚马逊卖家账号，可以用手机吗？

非常不建议。手机最大的问题是会自动连接已知WiFi，你控制不了它当前走的是哪个外网IP，一旦连上别人用过的网络，风险就不归你管了。注册和日常运营都放在固定的电脑环境里做。

### 美国站和欧洲站共用一套网络，会互相牵连吗？

同一套资料开的各站点之间确实存在关联记录，但一个站点出问题拖垮其他站点的情况不算常见——亚马逊本身就支持卖家在多个站点开店，有卖家美国站和英国站用同一根网线、同一台电脑，英国站因侵权被封后美国站照常经营。不过极端情况下也发生过两个站点一起被移除销售权限的案例，所以各站点的合规（尤其欧洲站的KYC）要分别做扎实。

### 换了办公地点或者宽带，账号会有问题吗？

换个网络本身不等于判死刑，但频繁在不同外网IP之间切换会增加风险，能固定就固定。办公地址如果发生变更，要及时联系亚马逊客服说明情况；注册时填写的公司地址在确认之后不能修改，不过完成注册后可以在卖家后台新增地址。

### 之前死过账号的电脑，还能用来做新账号吗？

可以，但要彻底翻新：重装系统、格式化硬盘，或者干脆换一台新主机；集成网卡找专业人员禁用，配一个USB外接网卡；路由器和猫也换掉，网线重签或者至少换一个外网IP。注册信息全部换新——邮箱、手机号、收款方式、注册地址，能不一样的地方都别相似。
